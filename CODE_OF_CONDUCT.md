# Verhaltenskodex

Dieses Projekt folgt dem [Contributor Covenant, Version 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).

Kurz zusammengefasst: Wir begegnen allen Beteiligten respektvoll, konstruktiv und ohne Belästigung oder Diskriminierung – in Issues, Pull Requests und allen anderen Projektkanälen.

Verstöße können vertraulich über [www.phinit.de](https://www.phinit.de) an den Maintainer gemeldet werden.
