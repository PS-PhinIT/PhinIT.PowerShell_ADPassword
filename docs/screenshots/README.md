# Screenshots

Hier werden die Screenshots der **aktuellen** Version abgelegt. Screenshots älterer Versionen werden beim Versionswechsel gelöscht.

Namensschema: `V<Version>_<Registerkarte>.png`, z. B.

- `V0.1.0_Einzelbenutzer.png`
- `V0.1.0_OU-Gruppe.png`
- `V0.1.0_Kennwortrichtlinie.png`
- `V0.1.0_FGPP.png`

Vor dem Hochladen alle echten Benutzernamen, Domänennamen und Kennwörter unkenntlich machen.
